# Windows Defender Real-Time Monitoring PowerShell Detection

## Introduction

This lab demonstrates how PowerShell activity related to Windows Defender configuration changes can be detected and investigated using Sysmon and Wazuh SIEM.

The objective of this lab was to simulate administrative PowerShell activity involving Windows Defender Real-Time Monitoring settings and analyze how the activity appears inside Wazuh.

The lab focuses on:
- PowerShell execution monitoring
- Sysmon Event ID 11 detection
- File creation telemetry
- Wazuh alert generation
- MITRE ATT&CK mapping
- SOC investigation workflow

---

# Lab Environment

| Component | Technology |
|---|---|
| SIEM | Wazuh |
| Endpoint Logging | Sysmon |
| Operating System | Windows 11 |
| Shell | Windows PowerShell |
| Detection Source | Microsoft-Windows-Sysmon/Operational |

---

# PowerShell Commands Executed

The following PowerShell commands were executed from an Administrator PowerShell session:

```powershell
Set-MpPreference -DisableRealtimeMonitoring $true
Start-Sleep -Seconds 2
Set-MpPreference -DisableRealtimeMonitoring $false
```

These commands:
- temporarily disabled Windows Defender Real-Time Monitoring
- paused execution for 2 seconds
- re-enabled Windows Defender protection

# Analysis Findings

The investigation determined that:
- the alert was generated after PowerShell execution
- PowerShell created a temporary `.ps1` file
- Sysmon detected file creation activity
- Wazuh classified the behavior as potentially suspicious
- the activity originated from legitimate administrative PowerShell usage

The file:

```text
__PSScriptPolicyTest...
```

is commonly generated by PowerShell during execution policy validation and script handling operations.

This behavior can appear suspicious because:
- PowerShell is frequently abused by attackers
- Temp directories are commonly used by malware
- script-based execution is heavily monitored in SOC environments

---

# Conclusion

This lab demonstrated how PowerShell administrative activity can generate Sysmon telemetry and trigger Wazuh detections.

Key takeaways:
- Sysmon successfully detected PowerShell file creation activity
- Wazuh generated a high severity alert based on suspicious behavior patterns
- MITRE ATT&CK mapping provided additional investigation context
- SOC analysts must validate alerts carefully to distinguish legitimate administration from malicious activity

This lab highlights the importance of:
- PowerShell monitoring
- Sysmon visibility
- SIEM correlation
- contextual alert investigation
- false positive analysis
